# Unit 08 — Social Assistance Policy & Law: Hard Mode

A single-page Traditional Chinese exam-practice website based on the uploaded 144-page course deck.

## Features
- Topic navigation for poverty concepts, measurement, anti-poverty arguments, the child/youth development account, the Social Assistance Act, and cross-topic comparisons.
- Challenging single-choice questions with hard and extreme scenario-integrated levels.
- Answer feedback and detailed explanations revealed only after submission.
- Source page references on every explanation.
- Session score, elapsed time, missed-question review, and repeatable wrong-question practice.
- No build tools or dependencies required.

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
This project lives in `projects/social-assistance-hard-mode/` on a dedicated feature branch. To publish it from the repository's existing Pages setup, merge the pull request into `main`, ensure Pages uses the repository root, then open:
`https://zzyrjr8drv-pixel.github.io/unique-id-website/projects/social-assistance-hard-mode/`

## Source fidelity
The content and legal descriptions are transcribed and paraphrased from the course deck, not independently updated legal advice. Some figures in the deck are explicitly labeled 2026 and should be treated as course-material snapshots. The website does not silently reconcile conflicting statements in the deck.

# Deckcraft

Deckcraft turns pasted content into an editable PowerPoint in the browser. The person making the deck chooses the style, the story flow, and the length, then reviews and edits each slide before exporting.

## Run it

Open `index.html` in a current browser. The PowerPoint export library is loaded from jsDelivr, so exporting needs an internet connection. The presentation content is processed in the browser and is not uploaded.

## What it includes

- Four styles: Studio, Editorial, Midnight, and Fieldnotes.
- Four story-flow directions and a manual-order option.
- Selectable slide count from 4 through 30, per-slide title and body editing, slide reordering, add, and remove.
- An automatic first-pass content check that flags short or repeated blocks for review. It uses simple text rules, so you make the final call.
- Live slide preview and downloadable editable `.pptx` output.

The slide arrangement uses the text and settings you choose; there is no AI rewrite step. Chinese text is kept as supplied and uses a Chinese-capable font setting in the PowerPoint.

# Path of Destiny — A Witcher Field Journal

A responsive, single-page interactive website for a university Vibe Coding midterm, inspired by *The Witcher 3: Wild Hunt*.

## Run locally
Open `index.html` in a modern browser. No build step, framework, account, or backend is required.

## Features
- Immersive landing page and introduction to the Continent
- Clickable monster bestiary: Leshen, Griffin, Noonwraith, and Fiend
- Interactive location explorer: White Orchard, Velen, and Novigrad
- Three-question Witcher personality quiz with calculated profile
- Branching original Leshen investigation with multiple outcomes
- Reflection section and official game / developer references
- Responsive layout for desktop and mobile

## Notes
All investigation scenarios, quiz questions, and outcomes are original classroom interpretations inspired by themes in the game. They are not official game quests or mechanics. This is an educational fan-made project and is not affiliated with CD PROJEKT RED.

Images are loaded from Unsplash and fonts from Google Fonts, so an internet connection improves the visual experience. Replace images with appropriately licensed or group-created assets before public distribution if required by your course.

# Genshin Impact — Journey Through Teyvat

A fan-made interactive website for a university game-world project.

## Open the website
Open `index.html` in a modern browser. The page is a self-contained HTML/CSS/JavaScript experience; internet access is needed for Google Fonts and remote illustrative images.

## What's included
- Introduction to Genshin Impact and the Traveler's journey
- Exploration, combat, elemental reactions, quests and co-op overview
- Clickable seven-element guide
- Regional field notes for Mondstadt, Liyue, Inazuma, Sumeru, Fontaine and Natlan
- Character introduction cards
- Three-question Traveler personality quiz
- Original branching story: **The Lanterns of Qingce**
- Reflection prompts and official reference links
